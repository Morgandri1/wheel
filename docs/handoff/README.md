# Handoff briefs

Wheel is now developed on Wheel. The local swarm that built M1 stood down on 2026-09-06; the
wheel-dev board on production takes over.

Each `<role>.md` here is that role's last act: what is done and provable on `main`, what was in
flight down to the file and the next step, the queue in priority order with the gate ID that
accepts each item, and — the section worth the most — the traps a fresh agent would walk into,
written by the agent that walked into them.

A cloud agent picking up a role reads its brief together with its CTX node. The brief is history
and intent; the CTX node is the standing contract. Where they disagree, the contract wins and the
brief tells you why someone thought otherwise.
